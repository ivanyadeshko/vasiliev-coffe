# Дизайн-система TV-меню

Направление: «premium dark coffee» — тёмная тёплая гамма из референсов
(чёрный борд + янтарная подсветка + аппетитная фуд-съёмка), но чище и
современнее: больше воздуха, крупная типографика, один акцентный цвет.

## 1. Палитра (CSS-токены)

```css
:root {
  --bg-0:      #120D0A;  /* глубокий эспрессо-чёрный — базовый фон */
  --bg-1:      #1C1512;  /* панели, шапка */
  --scrim:     linear-gradient(90deg, rgba(18,13,10,0) 0%, rgba(18,13,10,.86) 22%, rgba(18,13,10,.94) 100%);
  --accent:    #E9A23B;  /* янтарь/карамель — цены, заголовки категорий, лого */
  --accent-hi: #FFC46B;  /* подсветка изменившейся цены (pulse) */
  --text:      #F4EAD9;  /* кремовый — названия позиций */
  --text-mut:  #A89A88;  /* описания, объёмы, лидеры-точки */
  --line:      rgba(244,234,217,.14); /* разделители */
}
```

Правила: акцент один на всю сеть экранов (узнаваемость бренда). Категорию
выделяем акцентом + тонкой линией, не плашкой. Никаких чистых белых (#FFF) —
только крем, чтобы не «звенело» на тёмном.

## 2. Типографика

Шрифты self-hosted (woff2, кириллица), без CDN:

| Роль | Шрифт | Размер @1920×1080 | Стиль |
|---|---|---|---|
| Заголовок экрана | Unbounded 600 | 64 px | caps, letter-spacing .02em |
| Заголовок категории | Unbounded 500 | 40 px | акцентный цвет |
| Название позиции | Manrope 600 | 32 px | крем |
| Описание/состав | Manrope 400 | 21 px | muted, max 2 строки |
| Объём | Manrope 500 | 20 px | muted |
| Цена | Manrope 700 | 34 px | акцент, `font-feature-settings:"tnum"` |

Компактная ступень (включается автоматически при переполнении):
позиция 28 px, описание 19 px, цена 30 px, межстрочные −15 %.

Минимальный кегль 19 px — читаемость с 3–4 метров.

## 3. Сетка и композиция (холст 1920×1080)

- Безопасные поля 64 px по периметру (ТВ-overscan).
- **Шапка** (высота 120 px): лого + название бренда слева, заголовок экрана,
  часы справа (опционально).
- **Витрина** — левая зона, где живёт анимация видеофона:
  - экраны напитков (1–2): витрина 45 % ширины, меню в 1 широкую колонку
    или 2 узкие справа;
  - экраны еды (3–4): витрина 33 %, меню в 2 колонки справа (позиции с
    описаниями занимают больше высоты).
- Видео лежит фуллскрин-слоем (object-fit: cover), но скомпоновано так,
  что «действие» происходит слева; справа кадр уходит в ровный тёмный фон
  (задаётся промтом Grok). Поверх — скрим-градиент `--scrim` для гарантии
  контраста текста при любом ролике.
- Строка позиции: `Название …………… цена` — точечный лидер цветом `--text-mut`,
  цена в колонке фиксированной ширины (не прыгает при смене цифр).
  Двойная цена: `220 / 260`, объём мелко под названием («350/450 мл»).

## 4. Принципы анимации

1. **Медленно и мягко.** Движение в кадре — slow motion / ambient: пар,
   стекающий мёд, медленный пролив молока, плавное падение ингредиентов.
   Ничего резкого, мигающего, зацикленно-дёргающегося.
2. **Анимация — фон, меню — фигура.** Видео никогда не залезает под текст
   ярким пятном: правая часть кадра тёмная + скрим.
3. **Бесшовность.** Два `<video>` с кроссфейдом ~1 с на стыке лупа;
   плейлист 2–3 роликов на экран, ротация каждые 1–3 прохода.
4. **Текста в видео нет.** Все надписи и цены — только HTML-слой.
5. **Смена цены**: кроссфейд 400 мс + один мягкий «вдох» цветом
   `--accent-hi` (1.5 с, ease-out). Новая позиция — фейд-ин 600 мс,
   удаление — схлопывание высоты 400 мс.
6. Уважение к эпилепсии/усталости глаз: без стробов, яркость видео
   приглушена (фильтр brightness .9 при необходимости).

## 5. Логотип

Словесный знак: **«МОККО»** в Unbounded 700, letter-spacing .1em, цвет
`--accent`. Рядом (слева) — эмблема из Grok: плоская янтарная иконка на
тёмном (чашка/пар), без текста. В шапке экрана логоблок высотой 56 px.
Текст «МОККО» всегда набирается шрифтом, никогда не берётся из растра —
генеративные модели ломают кириллицу.

## 6. Тон контента

Названия — как в меню владельца, без «улучшательства». Составы — в
описании через запятую, с маленькой буквы. Вкусы ассортимента
(милкшейки, лимонады) — списком-чипами мелким кеглем под позицией.
