# МОККО — анимированное TV-меню

4 экрана 16:9 (`/screen.php?id=1..4`) + админка (`/admin/`). PHP 8.3, без БД:
данные в `data/*.json`. Спецификация — `docs/superpowers/specs/`, дизайн —
`docs/design-system.md`, промты графики — `docs/grok-prompts.md`.

## Запуск локально

    docker compose up -d
    open http://localhost:8080/

Пароль админки по умолчанию: `mokko2026`. Сменить:

    docker compose exec web php /var/www/bin/set-password.php НОВЫЙ_ПАРОЛЬ

Шрифты уже в `public/assets/fonts/fonts.css`; при чистом клоне woff2-файлы
скачиваются заново: `./bin/fetch-fonts.sh` (нужна сеть).

## Тесты

    docker compose exec web php /var/www/tests/run.php

## Графика (Grok Imagine)

Постеры, логотип и все видеоролики сгенерированы Grok (промты —
`docs/grok-prompts.md`). Ролики используются как есть, в нативном
разрешении и fps Grok (720p/24, reference_to_video может отдавать 480p) —
без апскейлов и интерполяции, так решено заказчиком.

Генерация видео требует, чтобы в Grok CLI был включён opt-in на хранение
coding data (`/privacy` внутри `grok`); при opt-out видео-инструменты
заблокированы (ZDR).

Как добавить/заменить ролик:

1. mp4 → `public/assets/video/`, постеры → `public/assets/img/`;
2. имена файлов прописать в `data/screen-N.json` → `media.videos` /
   `media.poster`; `media.hold_seconds` — пауза на финальном кадре
   (плеер доигрывает клип до конца, замирает на hold_seconds, затем
   кроссфейдом переходит к следующему клипу плейлиста);
3. экран подхватит на очередном поллинге. Без роликов витрина показывает
   постер, без постера — фирменный градиент; это штатные режимы.

Раскладка витрины: на экране 1 видео — панель в левой трети экрана
(объект в ролике держится по центру кадра, cover-кроп показывает
центральную треть); на экранах 2–4 видео фоновое с затемнением справа.

## Деплой на хостинг

- Залить проект; docroot веб-сервера → `public/`.
- `data/` должна быть вне docroot и доступна PHP на запись.
- Прогнать `bin/fetch-fonts.sh` и `bin/make-kenburns.sh` (или залить готовые
  `assets/fonts/` и `assets/video/` целиком).
- Задать пароль админки. Отдать владельцу 4 ссылки на экраны и ссылку на
  админку.

## Видео на экранах и журнал

Экран сначала целиком скачивает клипы своих сцен (лоадер с эмблемой и
процентами поверх постера), хранит их в IndexedDB браузера и играет
локально — слабый Wi‑Fi на показ больше не влияет. После перезагрузки
клипы берутся из IndexedDB без лоадера; заменённый на сервере файл (новый
mtime/размер) экран докачивает фоном и переключается без паузы. При сбое
сети — «Нет связи · повтор через N с», повторы бесконечные.

События экранов (загрузка, ошибки плеера, JS-ошибки, heartbeat раз в
10 мин) пишутся в `data/logs/screens-YYYY-MM-DD.jsonl`, хранятся 30 дней:

    ssh root@199.189.248.174 'tail -f /opt/vasiliev-coffee/data/logs/screens-$(date +%F).jsonl'
    ssh root@199.189.248.174 'cat /opt/vasiliev-coffee/data/logs/screens-*.jsonl' | jq -c 'select(.level != "info")'

## Экраны у владельца

На каждом ТВ (43″) открыть свою ссылку в полноэкранном режиме браузера.
Экран сам опрашивает сервер (раз в 60 с, настраивается в
`data/settings.json`), сам перезагружается ночью (04:00) и переживает обрывы
сети: последнее меню кэшируется в localStorage. Скрыть закончившуюся позицию
(стоп-лист), поменять цену, добавить или удалить позицию — всё в админке,
кнопка «Сохранить»; экраны обновятся сами в течение минуты, плавно и без
перезагрузки.
