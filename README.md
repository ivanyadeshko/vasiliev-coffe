# МОККО — анимированное TV-меню

4 экрана 16:9 (`/screen.php?id=1..4`) + админка (`/admin/`). PHP 8.3, без БД:
данные в `data/*.json`. Спецификация — `docs/superpowers/specs/`, дизайн —
`docs/design-system.md`, промты графики — `docs/grok-prompts.md`.

## Запуск локально

    docker compose up -d
    open http://localhost:8080/

Пароль админки по умолчанию: `mokko2026`. Сменить:

    docker compose exec web php /var/www/bin/set-password.php НОВЫЙ_ПАРОЛЬ

Шрифты уже в `public/assets/fonts/fonts.css`; при чистом клоне woff2-файлы
скачиваются заново: `./bin/fetch-fonts.sh` (нужна сеть).

## Тесты

    docker compose exec web php /var/www/tests/run.php

## Графика (Grok Imagine)

Постеры экранов и логотип сгенерированы Grok (`public/assets/img/`).
Видеолупы сейчас — плавный кен-бёрнс-зум из постеров:

    ./bin/make-kenburns.sh   # нужен ffmpeg; кладёт mp4 в public/assets/video/

Когда в аккаунте xAI будет снята блокировка Zero Data Retention для
image-to-video, настоящие ролики генерируются по промтам из
`docs/grok-prompts.md` и кладутся так:

1. mp4 → `public/assets/video/`, постеры → `public/assets/img/`;
2. имена файлов прописать в `data/screen-N.json` → `media.videos` /
   `media.poster` (можно несколько роликов — плеер ротирует их с кроссфейдом);
3. экран подхватит на очередном поллинге. Без роликов витрина показывает
   постер, без постера — фирменный градиент; это штатные режимы.

## Деплой на хостинг

- Залить проект; docroot веб-сервера → `public/`.
- `data/` должна быть вне docroot и доступна PHP на запись.
- Прогнать `bin/fetch-fonts.sh` и `bin/make-kenburns.sh` (или залить готовые
  `assets/fonts/` и `assets/video/` целиком).
- Задать пароль админки. Отдать владельцу 4 ссылки на экраны и ссылку на
  админку.

## Экраны у владельца

На каждом ТВ (43″) открыть свою ссылку в полноэкранном режиме браузера.
Экран сам опрашивает сервер (раз в 60 с, настраивается в
`data/settings.json`), сам перезагружается ночью (04:00) и переживает обрывы
сети: последнее меню кэшируется в localStorage. Скрыть закончившуюся позицию
(стоп-лист), поменять цену, добавить или удалить позицию — всё в админке,
кнопка «Сохранить»; экраны обновятся сами в течение минуты, плавно и без
перезагрузки.
